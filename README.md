# Kūaotunu Wildfire Decision Support Tool (NetLogo ABM & MATLAB Analytics)

This repository contains the simulation code, visualization scripts, and empirical datasets for the **2025 Kūaotunu Wildfire (Black Jack Fire)** modeling report (ENVSCI704 / FENZ Tender 5 RFP).

## 📁 Repository Structure

- `NetLogo_Model/`: Contains the main NetLogo agent-based simulation code (`.nlogo`).
- `MATLAB_Scripts/`: Contains MATLAB scripts (`.m`) for generating figures 2 to 8.
- `Data_CSV/`: Raw simulation export datasets (`.csv`) generated via BehaviorSpace.

## 🚀 How to Run
1. **NetLogo**: Open `NetLogo_Model/Kuaotunu_Wildfire_Model.nlogo` in NetLogo 6.x+, click `Setup`, then `Go`.
2. **MATLAB**: Run the corresponding `.m` script in `MATLAB_Scripts/` with the matching `.csv` file in your working directory.
